# APKforge on GitHub Pages

## Upload

Upload the contents of this folder to the root of your GitHub Pages repository. Do not upload the ZIP file itself. After uploading, enable Pages from **Settings → Pages**, choose your deployment branch, and choose **/ (root)**.

## Automatic repository builds

In APKforge, choose **Repository link** and enter a public GitHub, GitLab, or
Bitbucket repository URL. The link is saved in your browser, and every build
fetches the latest commit from the repository's default branch. The Android
repository must include `gradlew` and its Gradle project files.
