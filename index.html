Start a build

This small control panel works with the repository that hosts it.

How it works

No server. No API key.
01

Upload source

Click the upload button and add your Android project files to the repository's main branch.

02

GitHub builds

Every upload starts the Android workflow automatically. GitHub installs dependencies and creates a release APK.

03

Download APK

Open the completed workflow, scroll to Artifacts, and download the APK ZIP file to your phone or computer.

ⓘ
Keep these files in the repositoryThe .github/workflows/android-apk.yml file is the build engine. Do not delete it when uploading your source code.
